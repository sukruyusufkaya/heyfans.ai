# Çok dillilik (i18n)

Desteklenen diller: **Türkçe (kaynak)**, İngilizce, Arapça (sağdan sola), İspanyolca, Fransızca, Portekizce (Brezilya), Almanca.
Altyapı kendi yazdığımız küçük bir katmandır (`src/i18n/`), ICU biçimi için `intl-messageformat` kullanır.

## Temel ilke: anahtar = Türkçe metin

Kodda metinler **Türkçe yazılmaya devam eder** ve `t()` ile sarılır; çeviri kataloğunda anahtar bu Türkçe metindir.

```tsx
t("Kaydet")
t("{count} yeni mesaj", { count })
```

- Türkçe arayüz değişmez (katalog Türkçe için boştur). Metni yeniden yazmayın; yalnız `${…}` değişkenlerini ICU `{değişken}` biçimine çevirin.
- Katalogda karşılığı olmayan metin Türkçe görünür, sayfa bozulmaz. Eksikleri test yakalar.
- Aynı Türkçe metin her yerde aynı çeviriyi alır. Farklı anlam gerekiyorsa Türkçe metni ayırt edin (ör. "Kapat" fiil / "Kapalı" durum).

## Dil seçimi

Sıra (`src/i18n/resolve.ts`):
1. `?lang=xx` (paylaşılabilir bağlantı, arama motoru; çereze yazılır),
2. kullanıcının seçimi (`hf_locale` çerezi),
3. hesap dili (`users.locale`),
4. **konum** (`x-vercel-ip-country`; çok dilli ülkede tarayıcı dili seçer),
5. tarayıcı dili (`Accept-Language`),
6. Türkçe.

Dil seçici (`components/i18n/language-switcher.tsx`) çereze ve hesaba yazar, sayfayı yeniden yükler. Kayıtta hesap dili o anki dil olur. E-postalar ve bildirimler hesap dilinde gider.
SEO: herkese açık sayfalarda `hreflang` alternatifleri `?lang=xx` ile üretilir (`app/layout.tsx`); `x-default` Türkçe adrestir.

## Nerede ne kullanılır

| Yer | Çevirmen | Biçimlendirici |
|---|---|---|
| Sunucu bileşeni, `generateMetadata`, server action, servis | `const t = await getT()` — `@/i18n/server` | `const { formatDate, formatMoney } = await getFormatters()` |
| İstemci bileşeni (`"use client"`) | `const t = useT()` — `@/i18n/client` | `const { formatDate } = useFormatters()` |
| Bileşen dışı sabit (etiket haritası, menü, seçenek listesi, zod mesajı) | `m("Aktif")` — `@/i18n/m`; gösterirken `t(değer)` | — |
| Başka bir kullanıcıya giden metin (e-posta, AI istemi) | `await getTranslatorFor(user.locale)` | `createFormatters(locale)` |

`useLocale()` / `await getLocale()` dil kodunu verir (`tr`, `en`, `ar`…). `useDirection()` / `getDirection()` → `ltr | rtl`.

### Kurallar

1. **Modül düzeyinde `t()` çağırmayın.** Sabitlerde `m()` kullanın, görüntülerken `t(LABELS[x])`.
2. **Değişken**: `` `${n} içerik` `` → `t("{n} içerik", { n })`. Sayılar için `count`/`n` adını kullanın; çevirmen çoğul biçimi ekler. Değişken adları çeviride aynen korunur.
3. **Cümle içinde etiket**: mümkünse cümleyi iki ayrı `t()` çağrısına bölün. Bölünemiyorsa
   `t.rich("<b>{n}</b> içerik bulundu", { n, b: (c) => <b>{c}</b> })`. Etiket adı serbesttir (`b`, `link`, `terms`, `privacy`…); aynı cümlede iki bağlantı varsa ayrı adlar kullanın. Çeviride etiketler aynen korunur. React anahtar uyarısı için `Children.toArray(t.rich(...))` ya da `components/fan/rich.ts` içindeki `rich()` kullanılabilir.
4. **Metin birleştirmeyin**: `t("Merhaba") + " " + name` yerine `t("Merhaba {name}", { name })`. Türkçe ek üreten yardımcıları (`'nın/'nin`) çevrilecek cümlelerde kullanmayın; cümleyi eksiz kurun ya da eki `{suffix}` değişkeni olarak geçin (çevirmen bunu atabilir).
4b. **Başlık parçaları**: Satırlara bölünmüş başlıklarda ("Gizlilik" + "Politikası") çevirmen parçaları cümle akışına göre çevirir; Almancada "Gizlilik" → "Unsere" olabilir. Bu yüzden başlık parçası olan tek kelimelik anahtarları başka yerde tek başına kullanmayın. Yeni başlıklarda tek `t.rich("Gizlilik <accent>Politikası</accent>", …)` tercih edin.
5. **Metadata**: `export const metadata = { title: "X" }` → `export async function generateMetadata() { const t = await getT(); return { title: t("X") }; }`.
6. **Sunucudan istemciye geçen metin**: sunucu bileşeni, istemci bileşenine **çevrilmiş** metin geçirir. İstemci bileşeni yalnız kendi içe aktardığı modüllerdeki `t()`/`m()` metinlerini çevirebilir. Çıkarıcı istemci kataloğunu içe aktarma grafiğinden hesaplar; sunucu modülündeki `m()` sabiti istemciye gitmez.
7. **Veritabanı içeriği** (kategori adı, hediye adı, platform planı adı/açıklaması/avantajları, ana sayfa bölümleri, yardım makaleleri, yasal sayfa bölümleri): tohum verisi `scripts/db/seed-data.ts` / `shared.ts` içinde `m()` ile işaretlidir. Sunucuda `t(kategori.ad)` ile gösterilir. Yöneticinin sonradan değiştirdiği metin çevrilmeden Türkçe görünür.
8. **Kullanıcı içeriği çevrilmez**: creator adı, biyografi, gönderi, sohbet mesajı, kullanıcı adı, e-posta, URL, kod, kimlik.
9. **Hatalar**: `new AppError("Türkçe mesaj")` aynen kalır; istemciye dönerken `toActionError` / `localizeError` (`@/lib/action-error`, yalnız sunucu) çevirir. Hata sınıfları `@/lib/errors` içindedir ve istemci koduyla paylaşılabilir; `@/lib/errors` sunucu çevirmenini içe aktarmamalıdır (tarayıcı paketine veritabanı sürücüsü sızar). Değişkenli mesaj: `new AppError("Gerekli: {required}.", "code", 400, { params: { required } })`. Özel hata sınıfının varsayılan mesajı `m("…")`. Zod mesajları `m("…")`. Form alanı hatasını gösterirken `t(message)`.
10. **Bildirim**: `notify(userId, { type, title: "{plan} planına yeni abone", params: { plan } })`. Gösterirken `t(n.title, n.data?.params)`. Oluştururken çevirmeyin.
11. **Biçimlendirme**: `@/lib/utils` içindeki `formatX` fonksiyonları yalnız Türkçedir (betik/test). Arayüzde `getFormatters()` / `useFormatters()` kullanın. `localeCompare(x, "tr")` → `compare`. `"tr-TR"` sabitleri → dil.
12. **Bilinçli çevrilmeyen görünür metin** (marka, örnek kod, dil adları): aynı ya da önceki satıra `// i18n-ignore` (JSX'te `{/* i18n-ignore */}`) yazın.
13. **Yön (Arapça)**: fiziksel sınıflar yerine mantıksal sınıflar kullanın: `ms-/me-`, `ps-/pe-`, `start-/end-`, `text-start/end`, `rounded-s/e`, `border-s/e`. Yön bildiren ikonlara (ok, chevron, gönder) `rtl:-scale-x-100` ekleyin. Kod tabanı `node scripts/i18n/rtl-codemod.mjs` ile bir kez dönüştürüldü.

## Araçlar

```bash
npm run i18n:check -- src/app/(fan)   # sarılmamış metinler (salt okunur; yol öneki isteğe bağlı)
npm run i18n:extract                  # katalogları eşitle + istemci bölgelerini üret (merkezi; paralel çalışırken çalıştırmayın)
npm run i18n:status                   # dil/parça başına eksik çeviri
```

- Katalog: `src/i18n/messages/<dil>/<parça>.json` (`{ "Türkçe": "çeviri" }`). Parçalar: shared, public, auth, fan, studio, admin, support, server, content.
- `src/i18n/generated/` dosyaları otomatik üretilir.
- `tests/unit/i18n.test.ts` şunları denetler:
  - her metnin 6 dilde çevirisi var,
  - değişkenler korunuyor,
  - ICU geçerli,
  - istemci bölgeleri güncel.

- İngilizce: sade, samimi, "you".
- İspanyolca: tarafsız, "tú".
- Fransızca: "tu" — arayüz Türkçede "sen" diliyle yazıldı.
- Portekizce: Brezilya, "você".
- Almanca: "du".
- Arapça: Modern Standart Arapça, erkek-kadın ayrımı olmayan hitap tercih edilir.
